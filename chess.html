📦 如何上傳至 GitHub 運行？

  1. 將此單一檔案重新命名為 index.html
  2. 在 GitHub 建立一個新的公開 Repository（例如命名為 xiangqi）。
  3. 透過網頁上傳或 Git 指令將 index.html 推送到主分支（main）。
  4. 前往 Repository 的 Settings > Pages，將 Source 設定為 main 分支與 / (root)。
  5. 儲存後數十秒即可透過 GitHub Pages 提供的網址隨時隨地和朋友雙人對打！
